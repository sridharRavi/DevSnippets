


## Features

- Create and delete code snippets
- Syntax highlighted code blocks
- Responsive UI with TailwindCSS
- PostgreSQL database integration
- REST API backend
- Cloud deployment with Render and Vercel



## Tech Stack

Frontend:
- React
- Vite
- TailwindCSS
- Axios

Backend:
- Node.js
- Express.js
- Prisma ORM

Database:
- PostgreSQL

Deployment:
- Vercel
- Render
